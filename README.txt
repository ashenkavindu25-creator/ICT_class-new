ICT with Ashen Disanayaka - landing page

Open index.html in a browser (internet needed for Google Fonts).

Folder:
  index.html       page content
  css/style.css    all styles and animations
  js/main.js       language switch, class cards, student lists, effects
  assets/          logo.png, ashen.jpg

Edit student data in js/main.js:
  S      = Top achievers (name, year, results, ICT grade, school, img)
  names  = full pass list names
  R      = results per year
Add a student photo: put it in assets/ and set img:'assets/photo.jpg'.
Phone/WhatsApp/email: edit the contact section in index.html.
